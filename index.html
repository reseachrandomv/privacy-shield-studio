          How 0 bytes leave your browser

          PrivacyShield Studio is a static page. After the HTML, CSS, fonts and icon library load, every tool runs entirely inside this tab. There is no backend, no analytics, no cookies and no upload endpoint. The page's Content-Security-Policy sets connect-src 'none', so the browser itself blocks any fetch, XHR, WebSocket or beacon.

          Native Web APIs doing the work

          • RegExpDetects and redacts secrets in your text.
          • FileReader + Canvas.toBlob()Reads and re-encodes images in memory.
          • URL & URLSearchParamsParses links and removes trackers.
          • crypto.getRandomValues()OS-level CSPRNG for keys and passwords.

          Verify it yourself

          1. Open DevTools (F12 or ⌘+⌥+I) and select the Network tab.
          2. Clear the log, then paste secrets, drop a photo, clean URLs and generate keys.
          3. Watch: no new requests appear. Only blob: URLs created locally for downloads.
          4. Go further: switch the Network throttle to Offline, or disconnect Wi-Fi. Every tool keeps working.
